## LinkPage-App

LinkPage-App es un proyecto básico desarrollado con **HTML**, **CSS** y **JavaScript** con fines educativos. Permite explorar cómo se estructura y construye una página de enlaces, ideal para quienes están comenzando en el desarrollo web.

*Creado para fines de aprendizaje para Openbox Ltda.*

## 🚀 Características

- Página de enlaces de ejemplo, similar a un "linktree".
- Uso de efectos visuales con [Vanta.js](https://www.vantajs.com/) y Three.js.
- Código simple y comentado para facilitar el aprendizaje.
- Estructura de carpetas clara: `.` `/img`, `/styles`.

## 📁 Estructura del proyecto

```
/
├── .github/       # Workflows de GitHub Actions
├── img/           # Imágenes y recursos gráficos
├── styles/        # Archivos CSS
├── index.html     # Contiene la página principal
└── README.md
```

## 🛠️ Instalación y uso

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/Naicriz/LinkPage-App.git
   ```
2. **Abre el archivo** `index.html` en tu navegador.
3. Personaliza los enlaces, imágenes y estilos según tus necesidades.

## 📦 Despliegue en GitHub Pages

El proyecto está preparado para ser desplegado en GitHub Pages mediante un workflow de Actions.
**Nota:** Para que las rutas absolutas funcionen, el archivo `index.html` y las carpetas `/img` y `/styles` deben estar en la raíz del deploy.
